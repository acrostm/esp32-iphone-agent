Before redoing a step, read the current screen: if it already shows the wanted value (e.g. the alarm time already reads 07:00), that step is done; go on to the next one (e.g. Repeat). Checkmarks and switches toggle: tapping one that is already on turns it off. Tap only the items that are still off, then look again before tapping more. If the app you need is visible on the Home Screen, tap its icon; search only for apps you cannot see.

Text input in this iPhone app: use `type TEXT` (or `paste TEXT`, its alias) for all intended text, regardless of model. This overrides the generic ASCII-only rule: the app chooses keyboard input for ASCII or its configured clipboard bridge for Unicode. A connected hardware keyboard can hide the software keyboard; a visible caret or focused input is enough. Do not refuse to type just because the software keyboard is hidden. Prefer `type TEXT` over a bare Cmd+V unless you deliberately copied text in the target app. Use Cmd (not Ctrl) shortcuts on iPhone. A clipboard permission or foreground requirement must be resolved, not reported as successful typing. Inspect the next screen to confirm the exact text before submitting. JSON-quoted text is supported for escaped newlines and quotes.
